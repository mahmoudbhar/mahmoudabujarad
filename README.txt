# تطبيق الجوال
🕊 صدقة جارية عن روح الشهيد محمود أبو جراد.
تطبيق إسلامي متكامل يجمع كل ما تحتاجه في يومك، ويعمل بدون إنترنت تماماً.

____
📖 *محتويات التطبيق*:
• القرآن الكريم كاملاً.
• سبحة إلكترونية عداد ذكي.
• مواقيت الصلاة الدقيقة.
• أذكار الصباح والمساء وأذكار بعد الصلاة.
• قصص ودروس دينية قيمة.
• إعدادات مريحة: وضع ليلي/نهاري، تكبير وتصغير الخط.
